# 💧 Sistema de Classificação de Consumo de Água

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)
![Water Management](https://img.shields.io/badge/Eco-Water--Saving-blue?style=for-the-badge)

O **Sistema de Classificação de Consumo de Água** é uma aplicação desenvolvida em Python para analisar o consumo mensal de água (m³) de diferentes tipos de imóveis e emitir alertas e recomendações de acordo com regras de negócio predefinidas.

---

## 🚀 Funcionalidades

- Categorização por tipo de imóvel: `comercial`, `casa` e `apartamento`.
- Avaliação do volume de água consumido em metros cúbicos (m³).
- Feedback dinâmico sobre a faixa de consumo: econômico, moderado ou excessivo.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 🐍
- **Controle de Versão:** Git e GitHub 🐙

---

## 🔧 Como Executar o Programa

1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Clone este repositório ou navegue até a pasta do projeto:

	```bash
	cd consumo-agua
	```

3. Execute o programa:

	```bash
	python main.py
	```

---

## 🌱 Objetivo

Incentivar o consumo consciente de água por meio de uma classificação simples e orientações que ajudam a identificar oportunidades de economia.
